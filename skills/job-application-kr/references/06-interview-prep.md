# 필기·면접·처우협의 준비

## 한국 채용 전형 흐름
대기업 공채/수시: 서류 → 인적성(필기) → 1차 실무(직무)면접 → 2차 임원(인성)면접 → 건강검진·처우협의
IT·스타트업: 서류 → 코딩테스트 또는 과제 → 기술면접 → 컬처핏/임원면접 → 처우협의
공공기관: 서류(블라인드) → NCS 필기(+전공) → 면접(PT·토론·인성) → 신원조회
경력직: 서류 → 실무면접 → 임원면접 → 레퍼런스(평판) 체크 → 처우협의

공고의 전형 절차를 확인하고 단계별 준비 계획을 날짜와 함께 만든다.

## 필기 단계
| 유형 | 대표 예 | 준비 포인트 |
|------|--------|------------|
| 대기업 인적성 | GSAT(삼성), SKCT(SK), LG Way Fit, HMAT(현대차) 등 | 회사별 최신 출제 영역은 매년 바뀜. 채용 공지와 최근 후기로 확인 후 계획 |
| 공공기관 NCS | 의사소통, 수리, 문제해결 등 직업기초능력 + 전공 | 기관별 출제 대행사·유형(모듈형/PSAT형/피듈형) 확인 |
| 인성검사 | 대부분의 기업 | 일관되게 솔직하게. 이상적인 답을 꾸미면 신뢰도 척도에 걸림 |
| AI역량검사 | 일부 기업 | 환경(조명, 카메라, 소음) 점검, 게임형 과제는 연습판으로 익숙해지기 |
| 코딩테스트 | 프로그래머스, 백준 기반 등 | 공고의 언어 제한, 시간, 응시 환경 확인. 유형별 기출 연습 |
| 과제전형 | 기획서, 디자인, 개발 과제 | 요구사항 체크리스트로 누락 방지. 제출 전 README에 의사결정 근거 |

시험 문제 유출본이나 대리 응시는 돕지 않는다.

## 면접 답변 구조
STAR를 한국 면접에 맞춰 **결론 → 상황 → 행동 → 결과 → 배운 점** 순서로 말한다. 1분~1분 30초.
경험당 꼬리질문 3단계("왜 그렇게 했나요?", "다른 방법은?", "다시 한다면?")까지 준비한다.

### 준비할 사례 (프로필에서 4~6개)
```
### 1. [사례명] (보여주는 역량)
결론: 
상황: 
행동: 
결과: (수치)
배운 점: 
예상 꼬리질문: 1) 2) 3)
쓰임: "가장 힘들었던 경험", "협업 갈등", "성과 낸 경험"
```

## 단골 질문
- **1분 자기소개**: 이름·직무 → 핵심 역량 2개(근거 한 줄씩) → 이 회사에서 할 일. 성장과정 금지.
- **지원동기 / 왜 우리 회사**: 자소서와 같은 근거, 다른 말로. 최근 회사 뉴스 하나 업데이트.
- **직무에 대해 아는 것**: 공고의 주요업무 + 실제 업무 흐름 이해 + 내가 바로 할 수 있는 부분.
- **이직 사유 (경력)**: 전 직장 비난 금지. "하고 싶은 일 / 성장 방향"으로 설명. 사실과 다르게 꾸미지 않는다.
- **공백기**: 무엇을 했는지 구체적으로(학습, 프로젝트, 자격 취득).
- **약점**: 실제 약점 + 진행 중인 보완.
- **입사 후 포부 / 5년 후**: 이 직무의 성장 경로 안에서.
- **희망 연봉 (면접 중)**: 범위로 답하거나 "처우협의 단계에서 회사 기준을 듣고 논의하고 싶습니다." 준비된 근거가 있으면 범위 제시.
- **마지막으로 할 말**: 면접에서 못 한 강점 하나 또는 답변 보완. 감사 인사만으로 끝내지 않음.

## 면접 유형별
- **실무/기술면접**: 이력서·포트폴리오 모든 줄이 질문 대상. 쓴 기술은 원리까지 설명 가능해야 함. 과제가 있었다면 개선점 질문 대비.
- **임원/인성면접**: 가치관, 조직 적합, 끈기. 짧고 확신 있게. 회사 사업·업계 흐름 질문 대비.
- **PT면접**: 주제 해석 → 현황 → 문제 → 해결안 → 기대효과·리스크. 준비 시간 배분 연습, 시간 엄수.
- **토론면접**: 이기는 게 아니라 합의를 만드는 역할. 상대 의견 요약 후 반론, 시간 관리, 결론 정리 역할.
- **영어면접**: 자기소개, 지원동기, 직무 경험 3개를 영어로 준비.
- **화상면접**: 카메라 눈높이, 조명, 배경, 인터넷, 이어폰. 메모는 화면 옆에 최소한으로.

## 면접관에게 할 질문 (2~3개)
- 이 포지션에서 입사 후 3~6개월 안에 기대하는 성과는?
- 팀 구성과 협업 방식, 코드리뷰/의사결정 방식은?
- 현재 팀이 가장 크게 풀고 있는 문제는?
- 이 팀에서 잘 적응한 분들의 공통점은?
- (전환형 인턴) 정규직 전환 평가 기준은?
연봉, 휴가, 복지는 1차 면접에서 먼저 꺼내지 않는다. 처우협의 단계에서 묻는다.

## 처우협의 (연봉 협상)
- 회사는 직전 연봉 증빙(원천징수영수증, 급여명세서)을 요구하는 경우가 많다. 사실대로 낸다. 부풀리지 않는다.
- 협상 근거: 직전 연봉, 시장 범위(`03-job-evaluation.md`의 출처, 추정치 명시), 담당할 역할 범위, 경쟁 오퍼(실제 있을 때만).
- 확인할 항목: 기본급/성과급/고정 수당 구분, 퇴직금 별도 여부, 포괄임금 여부, 수습 조건, 직급, 입사일, 사이닝 보너스, 스톡옵션 조건(행사가, 베스팅).
- 구두 합의는 **처우 확정 메일이나 근로계약서로 받은 뒤** 현 직장에 퇴사 통보한다.
- 연봉 숫자 조언은 정보 제공 수준. 최종 판단은 사용자.

## 결과 대기와 연락
- 회사가 안내한 발표일까지는 기다린다. 발표일이 지나고 2~3영업일 지나도 연락이 없으면 담당자에게 짧게 문의.
- 불합격 연락에도 짧게 감사 회신하면 재지원 시 손해 없음.
- 결과는 `tracker.csv`의 상태에 반영: 작성중 → 지원완료 → 서류합격 → 필기합격 → 1차합격 → 최종합격/불합격 → 입사/포기.

## 모의면접 진행 규칙
사용자가 모의면접을 요청하면:
1. 회사·직무·면접 유형(실무/임원/PT/영어) 확인
2. 1분 자기소개로 시작 → 자소서·이력서 기반 질문 → 직무 질문 → 꼬리질문 → 압박 질문 1개
3. 한 번에 한 질문. 답변마다 짧은 피드백: 좋았던 점, 고칠 점, 더 맞는 사례
4. 끝에 전체 총평과 다시 연습할 질문 3개
