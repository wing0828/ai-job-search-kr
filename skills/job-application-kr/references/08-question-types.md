# 자소서 문항 유형집 · NCS · 지원서 양식

회사별 실제 문항은 해마다 바뀐다. 이 파일은 **문항이 묻는 의도와 구성 틀**만 정리한다. 실제 문항·글자수는 반드시 그해 공고에서 확인한다. 합격 자소서 원문은 저작권 문제로 싣지 않고, 참고하더라도 문장을 옮기지 않는다.

## 1. 문항 유형 → 의도 → 구성

| 유형 | 자주 보이는 표현 | 평가자가 보는 것 | 구성 틀 | 흔한 실수 |
|------|----------------|----------------|--------|----------|
| 지원동기·포부 | "지원한 이유와 입사 후 이루고 싶은 목표" | 회사·직무 이해, 오래 다닐 사람인지 | 산업 → 회사 → 직무 → 1년·3~5년 계획 | 회사 칭찬만, "성장하고 싶다" |
| 직무역량 | "직무 수행에 필요한 역량을 갖추기 위해 노력한 경험" | 바로 쓸 수 있는 능력, 근거 | 역량 한 줄 → 사례 → 행동(40%+) → 결과 → 직무 적용 | 수강 목록 나열 |
| 성장과정·가치관 | "본인을 가장 잘 표현하는 경험", "가치관에 영향을 준 사건" | 일하는 태도의 뿌리 | 사건 하나 → 바뀐 행동 → 지금의 일하는 방식 | 출생·가족 소개 |
| 협업·갈등 | "팀 내 갈등을 해결한 경험" | 조율력, 상대 이해 | 상황 → 상대 입장 파악 → 내 행동 → 관계·결과 | 상대를 깎아내림 |
| 도전·실패 | "목표를 세우고 도전한 경험", "실패에서 배운 점" | 회복력, 원인 분석 | 목표 → 실패 인정 → 원인(내 몫) → 바꾼 행동 → 재시도 결과 | 실패를 성공담으로 포장 |
| 창의·문제해결 | "기존 방식을 개선한 경험" | 문제 정의 능력 | 기존 방식의 문제 → 대안 비교 → 선택 근거 → 효과 | 아이디어만 있고 실행 없음 |
| 윤리·원칙 | "원칙을 지켜 손해를 감수한 경험" | 신뢰성 | 유혹 상황 → 판단 근거 → 결과·대가 | 극적인 각색 |
| 회사·산업 이슈 | "최근 이슈에 대한 견해" | 관심 깊이, 논리 | 이슈 요약(출처) → 의견 → 근거 → 직무에서 할 일 | 뉴스 요약만 |
| 자유 기술 | "자유롭게 기술", "추가로 하고 싶은 말" | 다른 문항에서 못 본 강점 | 남은 강점 하나를 사례로 | 감사 인사·다짐으로 채움 |

## 2. 기업 유형별 경향 (일반론)

- **대기업 공채:** 문항 수가 많고 지원동기·직무역량·가치관이 고정적으로 나온다. 인재상·핵심가치 키워드를 문항에 맞춰 사례로 보여준다.
- **IT·스타트업 수시채용:** 자소서 없이 이력서·포트폴리오만 받거나, "왜 우리 팀인가" 같은 짧은 문항 1~2개. 기술블로그·제품을 써 본 경험이 강하다.
- **공공기관:** NCS 직업기초능력에 맞춘 문항, 블라인드 규정 엄격. 아래 3절.
- **금융권:** 직무역량과 윤리·원칙 문항 비중이 높은 편. 금융 이슈 견해 문항이 자주 나온다.
- **경력직:** 자소서 대신 경력기술서 중심. 문항이 있으면 이직 사유·입사 후 기여에 집중.

## 3. NCS 기반 채용 (공공기관)

### 직업기초능력 10개 영역
의사소통능력, 수리능력, 문제해결능력, 자기개발능력, 자원관리능력, 대인관계능력, 정보능력, 기술능력, 조직이해능력, 직업윤리.
기관마다 이 중 일부를 골라 자소서 문항과 필기시험에 쓴다. 공고의 **직무기술서**에 어떤 능력을 보는지 적혀 있다.

### 직무기술서 활용 순서
1. 공고 첨부파일의 직무기술서를 연다(대개 HWP/PDF).
2. "필요지식", "필요기술", "직무수행태도"와 "직업기초능력" 항목을 표로 옮긴다.
3. 프로필에서 각 항목을 뒷받침하는 사실을 매핑한다. 근거 없는 항목은 비워 둔다.
4. 자소서 문항마다 대응하는 능력을 정하고, 그 능력이 드러나는 **행동**을 쓴다.
5. 직무기술서의 능력단위명이 낯설면 NCS 국가직무능력표준 사이트(ncs.go.kr)에서 같은 이름을 검색해 세부 내용을 확인한다.

### 경험·경력 기술서
일부 기관은 "경험기술서"(보수 없는 활동)와 "경력기술서"(보수 받은 일)를 따로 받는다. 양식 구분대로 나누고, 블라인드 목록(`02-writing-style.md`)을 지킨다.

## 4. 지원서 양식 (HWP·DOCX·PDF)

- 공공기관·중견기업은 HWP 지정 양식이 많다. 칸을 임의로 늘리거나 서식을 바꾸지 않는다.
- `hwp` 스킬이 설치되어 있으면 HWP 양식을 읽고 칸 채우기에 쓴다. 없으면 칸별 내용을 텍스트로 정리해 사용자가 붙여넣게 한다.
- DOCX 양식은 `docx` 스킬, PDF 제출은 변환 후 글자 깨짐·페이지 수를 확인한다.
- 칸 글자수 제한이 있으면 `scripts/charcount.py`로 칸별로 잰다.
- 제출 전 `scripts/precheck.py`로 블라인드·다른 회사명을 검사한다.

## 5. 기업 인원 추이 (국민연금 사업장 데이터)

국민연금 가입자 수, 월별 신규 취득·상실 인원으로 회사의 성장·이탈 추세를 볼 수 있다. 이 스킬은 따로 조회 도구를 넣지 않았다(공공데이터포털 활용신청·키가 필요한 방식이라서).
- 간단히: 크레딧잡 같은 공개 서비스의 인원 추이를 웹 검색으로 확인하고 출처를 적는다.
- 선택: 공개 스킬 모음 nomadamas/k-skill의 `national-pension-workplace`가 설치되어 있고 사용자가 키를 등록해 두었다면 그것을 쓴다.
- 둘 다 안 되면 "미확인"으로 둔다.
